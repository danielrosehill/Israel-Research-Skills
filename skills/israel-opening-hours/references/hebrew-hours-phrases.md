# Hebrew opening-hours phrases

Capture the merchant's Hebrew wording **verbatim** before translating it. The
wording is the rule.

## Shabbat- and holiday-relative phrases

| Hebrew | Meaning | Rule |
|---|---|---|
| כניסת השבת / כניסת שבת | Shabbat begins | candle lighting |
| צאת השבת / מוצאי שבת / מוצ"ש | Shabbat ends / Saturday night | havdalah |
| עד כניסת השבת | until Shabbat | close at candle lighting |
| עד שעה לפני כניסת השבת | until an hour before Shabbat | close at candle lighting − 60 min |
| עד שעתיים לפני כניסת השבת | until two hours before Shabbat | candle lighting − 120 min |
| שעה לאחר צאת השבת / שעה אחרי צאת השבת | an hour after Shabbat ends | open at havdalah + 60 min |
| במוצ"ש מ-20:00 | Saturday night from 20:00 | fixed time, but only after havdalah. In summer havdalah can be later than 20:00. |
| ערב שבת / יום ו׳ | Friday | |
| ערב חג | eve of a festival | treat like Friday |
| חג / יום טוב | festival day | treat like Shabbat |
| חול המועד | intermediate festival days (Pesach, Sukkot) | reduced hours; low confidence |
| ימי צום | fast days | |
| סגור בשבת / שומר שבת | closed on Shabbat / Shabbat-observant | |
| פתוח בשבת | open on Shabbat | |
| פתוח 24/7 / פתוח מסביב לשעון | open around the clock | |

## Days and hours vocabulary

| Hebrew | Meaning |
|---|---|
| יום א׳ … יום ה׳ | Sunday … Thursday |
| יום ו׳ | Friday |
| שבת | Saturday |
| א׳–ה׳ | Sun–Thu (never render as Mon–Fri) |
| שעות פתיחה | opening hours |
| קבלת קהל | counter / walk-in reception hours (offices) |
| מוקד טלפוני / מענה טלפוני | phone line hours |
| מענה אנושי | hours with a human on the line, as opposed to the automated menu (IVR) |
| בתיאום מראש / בזימון תור | by appointment |
| ללא תור | walk-in |
| שעון קיץ / שעון חורף | summer / winter timetable |
| למעט | except |
| סגור | closed |

Watch for a single-day exception inside a range. For example,
`א׳–ה׳ 08:00–13:00, ביום ג׳ גם 16:00–18:00` gives Tuesday a second, afternoon
window. Summaries often lose it, and it may be the only slot a working person
can use.
