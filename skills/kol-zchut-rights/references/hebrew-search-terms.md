# Hebrew search terms by domain

✓ means the term is an exact Kol Zchut article title. The titles were checked
with the site's title-suggestion API on 2026-10-16. Unmarked terms are good
search terms, but not exact titles. Brand-new titles can appear, and titles can
be renamed, so search rather than hard-coding a URL.

## Search tips

- Broad words (`עבודה`, `דיור`, `צרכנות`) return portal pages. Add the
  situation: `פיטורי עובדת בהיריון`, `עזיבת דירה לפני סוף החוזה`.
- To narrow by group, add it to the query: `לאזרחים ותיקים`, `לעולים`,
  `לחיילים משוחררים`, `לנכים`.
- The site uses both full and defective spelling, so try both if recall is low:
  `זיקנה` / `זקנה`, `היריון` / `הריון`.
